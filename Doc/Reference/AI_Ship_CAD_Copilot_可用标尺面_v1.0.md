# AI Ship CAD Copilot 可用标尺面

版本：v1.0  
日期：2026-09-08  
用途：记录当前已知的标尺面命名范围和自然语言转换规则

---

## 1. 可用范围

以下范围均包含起点和终点：

| 轴向 | CAD 名称前缀 | 最小名称 | 最大名称 | 数量 |
|---|---|---|---|---:|
| X 轴 | `FR` | `FR-10` | `FR200` | 211 |
| Y 轴 | `SL` | `SL-40` | `SL40` | 81 |
| Z 轴 | `LV` | `LV-5` | `LV50` | 56 |

共记录 348 个标尺面。

标准名称生成规则：

```text
X 轴：FR{整数}，整数范围为 -10～200
Y 轴：SL{整数}，整数范围为 -40～40
Z 轴：LV{整数}，整数范围为 -5～50
```

零位名称分别为 `FR0`、`SL0` 和 `LV0`，不写成 `FR-0`、`SL-0` 或 `LV-0`。

---

## 2. X 轴肋位转换规则

在 `-10～200` 范围内，下列用户表达转换为统一的 `FR` 名称：

| 用户表达 | 规范化结果 |
|---|---|
| `第100肋位` | `FR100` |
| `100号肋位` | `FR100` |
| `FR 100` | `FR100` |
| `fr100` | `FR100` |
| `第-10肋位` | `FR-10` |

例如：

```text
用户输入：请在第100肋位创建一块14mm厚的AH36板架
定位面规范化结果：FR100
提交 CAD 的 referenceName：FR100
```

---

## 3. Y 轴和 Z 轴名称规范化

当前只规范化标准前缀的大小写与空格，不定义额外中文别名：

| 用户表达 | 规范化结果 |
|---|---|
| `sl -40` | `SL-40` |
| `SL 0` | `SL0` |
| `lv -5` | `LV-5` |
| `LV 50` | `LV50` |

如需增加“左舷第 N 纵剖面”等中文别名，应先确认 CAD 业务含义，再更新本文件和自动化测试。

---

## 4. 与 CAD 校验的职责边界

- 本文件记录已知命名范围，用于输入规范化和演示。
- Agent 不查询当前 CAD 工程中的定位面对象，也不使用 `reference_plane_id`。
- 在已知范围内匹配到的名称会转换成标准名称。
- 不在已知范围内或不符合规则的名称不会被 Agent 猜测转换，仍交给 CAD 最终判断。
- `X=10000` 等坐标表达式不是本文件定义的标尺面名称，不转换为 `FR100`。
- 真实 CAD 返回定位面不存在、不可用或不唯一时，由 CAD Backend 返回结构化错误。

## 5. 维护规则

运行时代码中的范围定义位于：

```text
tools/ruler_plane_tools.py
```

修改范围或别名时，必须同步更新：

1. 本 Markdown 文件。
2. `tools/ruler_plane_tools.py` 中的 `RULER_PLANE_RANGES`。
3. `tests/test_ruler_plane_tools.py` 中的边界和别名测试。
4. Agent Graph 中与定位面规范化有关的测试。

本文件是业务规则说明，不应在运行时直接解析 Markdown 生成 CAD 参数。
