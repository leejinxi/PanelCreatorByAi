# 1. 项目背景

## 1.1 项目来源

公司黑客松项目，主题：

> AI + 业务场景

结合船舶CAD软件结构设计业务，探索AI Agent技术在工业软件中的应用。

---

## 1.2 项目目标

开发一个AI辅助船舶结构建模助手，实现：

> 用户通过自然语言描述船体结构需求，AI理解设计意图，生成结构参数，并调用CAD接口自动创建结构模型。

目标不是替代设计工程师，而是降低CAD建模操作成本，提高结构建模效率。

# 3. 当前MVP范围（30天版本）

## 3.1 核心功能

自动创建船体板结构（Plate）。

用户输入：

例如：

> 在FR100平面创建板，上边界依赖Panel_10，下边界Z=0，左边界Curve_30，厚度14mm，材料AH36。


AI输出标准结构定义：

```json
{
    "type": "plate",

    "reference_plane":
    {
        "type":"FR",
        "name":"FR100"
    },

    "boundaries":
    {
        "top":"Panel_10",
        "bottom":"Z=0",
        "left":"Curve_30"
    },

    "thickness":14,

    "material":"AH36"
}
````

然后调用CAD创建接口。

# 8. RAG知识库设计

## 8.1 RAG作用

RAG负责：

> 船舶结构专业知识

不负责：

> 当前CAD模型状态

---

## 8.2 RAG内容

### 船体坐标系

例如：

```
FR:
Frame，船体横向参考面

WL:
Water Line

BL:
Base Line

CL:
Center Line
```

---

### 结构对象定义

例如：

```
Plate:
船体板结构

Panel:
板架结构对象

Curve:
几何边界对象

Stiffener:
加强构件
```

---

### 建模规则

例如：

```
板结构创建需要：

1.参考平面

2.边界约束

3.厚度

4.材料

```
