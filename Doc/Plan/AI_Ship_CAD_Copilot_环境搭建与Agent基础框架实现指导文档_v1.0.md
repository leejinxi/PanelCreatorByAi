# 3. 开发环境

使用独立Conda环境：

ai_cad_agent

目的：

-   隔离AI应用依赖
-   方便后续内网部署
-   保证运行环境稳定

# 7. 业务对象调整

初始：

create_plate()

调整：

create_panel()

原因：

船舶结构设计中的核心业务对象是板架Panel，而不是单独板件Plate。

Panel包含：

-   Reference Plane
-   Boundary
-   Thickness
-   Material

更加符合CAD结构设计流程。

# 10. 当前关键技术决策

## 不直接让LLM调用CAD

采用：

LLM

↓

业务对象Schema

↓

CAD Tool

↓

CAD API

原因：

-   降低耦合
-   提高可维护性
-   适应CAD接口变化

## 当前暂不接入RAG

↓

执行动作

-   船舶结构知识
